# 05 UI

とにかくきれいで、使いやすく、サクサク動くこと(01 §1)。この文書は、画面の構成・操作・見た目の決めごとと、それを確かめる方法。

| 環境設定 | `/settings/{tables,forms,mcp}`。ワークスペース全体に効く設定。管理者だけ(§11) |

最初に開くのは、お気に入りの先頭(「今日」のタスク)。Todoist の代わりなので、1 日はそこから始まる。

## 2. ビュー

**一覧** — 列はビューの定義の幅の比で画面いっぱいに配る(狭いときは 7 割まで縮め、それ以下は横スクロール)。見出しを押すと並び替え(昇順 → 降順 → ビューの既定)。金額の列があれば下に合計。タスクのように完了できるテーブルは、先頭にチェックが付き、輪の色が優先度。

**カンバン** — 選択肢の列(`group_by`)ごとに縦の列。カードをドラッグするとその値が変わる。列の見出しに件数と、`sum_field` があれば合計。列の「+」は、その値を最初から入れて作成を開く。`hidden_groups`(完了済みなど)は列にも出さず、取りにも行かない。

**レポート** — 上に数字のタイル、下にグラフ。ビューの定義(`widgets`)を読み、集計 API の結果をそのまま描く。**画面は計算しない。**

**パネルの関連リスト** — タスクは未完了だけを出し、「完了済みの n 件も表示」で開く。「+ 追加」は、開いているレコードを関連先(取引先責任者を開いていればその人)に入れた状態で始まる。

## 3. キーボード

| キー | 動作 |
|---|---|
| `Q` | タスクを追加。レコードを開いていれば、それが関連先に入る |
| `/` / `Ctrl+K` | 検索とコマンド |
| `G` → `1…9` / `G` → `H` | 上から n 番目のテーブルへ / 今日のタスクへ |
| `1…9` | ビュー(タブ)を切り替える |
| `N` / `F` | レコードを作成 / このテーブルを絞り込む |
| `J` `↓` / `K` `↑` | 次の行 / 前の行。パネルを開いたままなら、中身も付いてくる |
| `Enter` / `E` / `Esc` | 開く / タスクを完了 / 閉じる(モーダル → パネル → 選択の順に 1 つずつ) |
| `M` / `?` | サイドバーを畳む / ショートカットの一覧 |
| `Backspace` | パネルで、たどってきた 1 つ前のレコードへ戻る |
| 活動の記録欄・書式付きの文字: `Ctrl+Enter` / `Esc` / `Ctrl+B` `Ctrl+I` | 記録する(確定)/ やめる / 太字・斜体。`- ` `1. ` `## ` `> ` の記法で箇条書き・見出し・引用 |
| テーブル設定: `Enter` / `Alt+↑↓` / `Ctrl+Enter` | 次の項目へ(末尾なら足す)/ 項目・選択肢の並べ替え / 保存 |

タスクの追加欄は、空白で区切った単語から期限と優先度と繰り返しを読む: `今日` `明日` `明後日` `来週` `週末` `月末` `来月` `金曜` `来週火曜` `3日後` `9/30` `9月30日` `30日` と `p1`〜`p4`、`毎日` `平日` `毎週` `隔週` `毎月` `毎年`(繰り返しだけ書けば最初の回は今日)。
「今日の議事録を送る」の「今日」は件名の一部として残す(単語として独立しているものだけを読む)。読み取った内容は欄の下に出し、手で選び直せばそちらが勝つ。

守ること:

- **日本語入力の変換中は、どのショートカットも反応させない**(`isComposing`。変換確定の Enter で送信されない)
- 文字を打っている最中は、1 文字のショートカットを効かせない
- 項目の編集は、Enter かフォーカスが外れたときに確定、Esc で取り消し

## 4. 見た目の決めごと

Anthropic 公式の `frontend-design` skill の手順(計画 → 既定の型に流れていないか見直す → 作る → 撮って見直す)で決めた。トークンの実体は `frontend/src/styles/index.css`。
skill の本文は、マーケットプレイス `claude-plugins-official` の `plugins/frontend-design/skills/frontend-design/SKILL.md`(プラグインとして入れていなくても、この手元の複製を読めば同じ手順を踏める)。

**方針**

1. **枠は静かに、データに色を。**画面の地は無彩色に近い灰、色はほぼ 1 色(クローバーの緑)。それ以外の色は、選択肢のタグ・優先度・期限切れのように**意味があるところだけ**に使う
2. **カードを並べない。**一覧は罫線だけの表、レポートは 1 枚の罫線入りの台帳(外枠 1 本と内側の細い線)。影の付いた同じ形のカードが並ぶ、よくある SaaS の見た目にしない。カードの形をしているのは、実際にカードであるカンバンだけ
3. **大胆さは 1 か所に。**いちばん触る場所 = タスクの完了チェックに、塗り・チェックの描画・行が抜ける動きを集中させた。ほかの動きは、開く・閉じる・差し込むの 3 種だけで、どれも 0.2 秒以内。勝手に動くものは無い(ログイン画面の四つ葉が 1 回開くのだけが例外)
4. **キーが見える。**主要な操作の横に、そのキーを小さく出す

**色**(明 / 暗)

| 役割 | 値 |
|---|---|
| 紙(本文の地)/ 枠(サイドバー)| `#ffffff` / `#141815`、`#f4f6f4` / `#0f1210`。灰にはごく薄く緑を混ぜ、アクセントと馴染ませた |
| 罫線 | `#e2e7e3` / `#262d28` |
| 文字(主・副・淡)| `#18201b` `#56615a` `#87918a` / `#e6ebe7` `#a3aea7` `#6f7a73` |
| アクセント(クローバー)| `#1c7c4d` / `#35a56c`。白文字とのコントラスト 5:1 |
| 注意・警告・情報 | `#c4372f` `#a96400` `#2467c0`(暗は明るい側の値) |
| タグ 9 色 | 灰・緑・青緑・青・紫・桃・赤・橙・琥珀。それぞれ淡い地 + 濃い文字の組。メタデータの `color` がこれを指す |

社名の clover から緑を取った。青や紫のアクセントは SaaS の既定の色で、どこのものか分からなくなるので避けた。

**文字**

- 和文は **OS に入っている UD 系のゴシックをそのまま使う**: Windows は BIZ UDP ゴシック(標準搭載。游ゴシックやメイリオより画面の小さい文字が読みやすい)、Mac / iOS はヒラギノ、Android は Noto Sans。和文フォントをダウンロードさせない(数 MB かかり、軽快さに反する)
- 欧文と数字は **Figtree**(同梱・約 20KB)。丸みのある形が四つ葉の印と合い、数字が素直で、桁揃え(tnum)を持つ。候補 12 書体を同じ文面で並べて選んだ。当初の Atkinson Hyperlegible Next は、ゼロに必ず斜線が入り、円の金額が並ぶ画面ではうるさいので外した
- **太さは 400 と 700 の 2 つだけ。**BIZ UDP ゴシックに中間の太さが無いので、全環境で揃える。強弱は太さではなく、大きさと文字色の 3 段で付ける
- 大きさは 11 / 12 / 13 / 14(本文)/ 16 / 20 / 26 / 36px。和文が潰れない 12px を実用の下限にする

**グラフ**(`dataviz` skill の手順)

- 形は役目で選ぶ: 1 つの数字はタイル、区分の比較は横棒、時間の流れは縦棒。円グラフ・2 軸・虹色は使わない
- 棒は細く(24px 以下)、値の側だけ角を 4px 丸め、基準線の側は直角。目盛り線は実線の細い線。値のラベルは要所だけ(横棒は先端、縦棒は頂上が 2 つ以下のときだけ)。残りは目盛り・ツールチップ・「表で見る」で読める
- 文字はグラフの色を着ない。色だけで区別させない。注意の数字は赤 + 警告の印
- 色は単色が `#0d8a54` / `#27a569`(面とのコントラスト 4.39 / 5.70)。フェーズのように順序のある区分は、同じ緑の濃淡 6 段(明: `#61ca8f` → `#005a34`、暗: `#005d36` → `#75dda2`)。**どちらも `dataviz` の検証スクリプト(`validate_palette.js --ordinal`)を明暗それぞれの面の色で通した値**。目で選ばない

## 5. 軽快さの作り

- **楽観更新**: 完了、編集、カンバンの移動、削除は、応答を待たずに画面を書き換える。キャッシュ済みの一覧すべてに変更を当て、条件から外れた行はその一覧から抜く。失敗したら戻して知らせる(`data/mutations.ts`)
- **取り消せることで守る**: 完了と削除は確認を挟まず、トーストの「元に戻す」で戻せる
- 画面の行き来では、手元のデータをすぐ出して裏で取り直す。タブやフィルタを変えても、前の結果を出したまま差し替える(空の瞬間を作らない)
- 最初に読む JS は約 110KB(gzip)。ドラッグ&ドロップ(カンバン・サイドバーの並べ替え・ビューの設定・テーブル設定で共有。約 30KB)、レポート、テーブル設定、環境設定、書式付きの文字のエディタ(Tiptap。約 135KB)は別ファイルで、要るときに読む(カンバンとレポートは開いて 0.8 秒後に裏で、エディタは記録欄に触れたときに)。**めったに開かない画面や重いライブラリを含む部品は、最初の束に入れない**(ビューの設定を静的に import しただけで dnd-kit ごと 30KB 増えた)
- ファイル名にハッシュの付く資源は 1 年キャッシュ、HTML は毎回確かめる(06)

## 6. 確かめ方

- `npm run e2e`(`frontend/e2e/smoke.mjs`)— 実ブラウザで、ログイン → キーで完了 → 元に戻す → タスク追加(期限の読み取り)→ 検索して開く → 編集して再読み込み → パネルと Esc の順序 → カンバンのドラッグ → 作成と必須の検証 → 絞り込み → サイドバー → ぱんくず(積む・戻る・ブラウザの戻る)→ テーブルの追加・設定・元に戻す・書き出し・取り込み・削除 → 活動の記録・完了したタスクの合成・@ の言及 → 桁区切りとパネルの幅 → サイドバーの並べ替えと Google ドライブ → ログアウト、を通す。開発サーバ、コンテナ、Access 越しの公開 URL のどれにも向けられる(`docs/runbook/01-operations.md`)
- 見た目は、スクリーンショットを撮って見直す(明・暗・スマホ幅)。和文の書体を本番と揃えるには、WSL から Windows のフォントを参照させる(同 runbook)

## 7. 分かっている制約

- 一覧は全件を描いている。数百件を超える前に、ページングと仮想スクロールを入れる(04 §9)
- 取引先のパネルに出るタスクは、その取引先に直接付いたものだけ。配下の商談に付いたタスクは出ない → Q-038
- ラベル、繰り返し、サブタスク、コメント、リマインダーは無い。Todoist をやめるのにどれが要るか → Q-037
- 一覧の見出しを押した並び替えは一時的で、保存されない(保存するのは「並び替え」のボタンから。§10)。レポートの部品は画面から編集できない(JSON の定義のみ)
- テーブル設定では、作成した項目の型と列名、参照先は変えられない。項目を外しても値は残る(02 §5)
- 取り込みは追加だけ。既にあるレコードの更新(キーでの突き合わせ)は無い
- 活動は、開いているレコードに直接付いたものだけが出る(取引先を開いても、配下の商談の活動は集まらない)。Q-038 と同じ論点で、必要になったら決める
- Google ドライブの「新規」はドキュメントだけ(スプレッドシート・スライドは「参照」で付ける)。フォルダの場所は固定(マイドライブ / CRM / テーブル名)

## 8. テーブル設定・取り込みと書き出し・ぱんくず(2026-09-22)

本人の指摘(J-020)で足した 3 つ。見た目は §4 の決めごとの延長で、新しい色・影・動きは足していない。

**テーブル設定**(`components/designer/TableDesigner.tsx`。サイドバーの「+」= 新規、歯車 →「テーブル設定」= 既存)

```
┌──────────────────────────────────────────────────────────────┐
│ [icon] 見積                                              ✕   │  題名がそのままテーブル名の入力欄。アイコンを押すと色とアイコン
│        列名 table_1                                          │
│──────────────────────────────────────────────────────────────│
│   項目名 5          データ型        必須  桁数・設定            │
│   見積番号   表示名  T 文字(1 行)    ■    255 文字         ⌄   │  先頭は表示名の項目(固定)
│ ⠿ 取引先            ↗ 参照      ⌄   □    [icon] 取引先 ⌄  ⌄ 🗑│  型ごとに、その型で決めることだけを出す
│ ⠿ 状況              ☰ 選択肢    ⌄   □    下書き 提出済み +1 ⌃ 🗑│
│     選択肢  ● 下書き ✕   ● 提出済み ✕   + 選択肢を追加          │  開いた行: 選択肢・入力例・列名
│ + 項目を追加                                                  │
│──────────────────────────────────────────────────────────────│
│ 作成日時と更新日時は自動で付きます      キャンセル [テーブルを作成]│
└──────────────────────────────────────────────────────────────┘
```

- **大胆さはこの表 1 か所に。**一覧と同じ「罫線だけの台帳」にして、カードや枠で囲まない。左端は題名の文字に揃える
- **キーボードだけで組める。**テーブル名 → `Enter` → 項目名 → `Enter` で次の行(末尾なら足す)。型を選ぶと、次に決める場所(選択肢の名前、参照先)へフォーカスが進む。空の行で `Backspace` を押すとその行が消える。`Alt+↑↓` で並べ替え(ドラッグでも)。`Ctrl+Enter` で保存
- **フォーカスの移動は必ず同期で行う**(`flushSync` で描いてから `focus()`)。次のフレームまで待つと、`Enter` に続けて速く打った文字が前の欄に入る(実際に踏んだ。runbook §4)
- 桁数・設定の欄は型で変わる: 文字は桁数(空なら制限なし)、数値とパーセントは小数の桁数、参照は参照先、選択肢は中身の要約(押すと開く)。ほかは「—」
- 確認は挟まない。書きかけで閉じたら、トーストの「編集に戻る」で続きから開く。保存は「元に戻す」で前の定義に戻る。テーブルの削除も「元に戻す」で戻る(02 §5)
- 変えられないもの(作成済みの型・列名・参照先、表示名の項目、業務ルールが使う項目の削除)は、欄を無効にして理由をツールチップで出す
- 画面は定義を組み立てて送るだけ。検証の最後の判断、既定のビューの用意、`created_at` などの付与はサーバ(04 §6)

**取り込みと書き出し**(`components/designer/ImportModal.tsx`、`data/exportTable.ts`)

- 書き出しは押したらすぐ落ちる(`取引先_2026-09-22.csv`)
- 取り込みは、置く(または選ぶ・貼り付ける)→ 見出しと項目の対応を見る → 取り込む、の 3 手。対応はサーバが推測した結果を出し、行ごとに直せる。直すたびに `dry_run` で検証し直し、「n 行のうち m 行を取り込めます」と、読めない行の理由を出す
- 取り込んだあとは「元に戻す」で、作成したレコードをまとめて消せる
- Excel の CSV(Shift_JIS)は、画面が UTF-8 で読めなければ Shift_JIS として読み直す

**ぱんくず**(`lib/usePeek.ts`、`components/record/RecordPanel.tsx`)

- `?peek=` の値を、`テーブル名:ID` をカンマでつないだ**経路**にした。末尾がいま開いているレコード、手前がたどってきたレコード。URL の共有と、ブラウザの戻る・進むがそのまま効く
- **パネルの中から開いたレコードは経路に積み、外(一覧・カンバン・検索)から開いたレコードは経路を始め直す**(`PanelScope`)。経路に既にあるレコードを開いたら、そこまで戻る(取引先 → 責任者 → 同じ取引先、で堂々巡りにしない)
- 表示は「[icon] 取引先の名前 › [icon] 責任者の名前 › [icon] 商談」。手前はレコードの名前(押すと戻る)、末尾はテーブル名(すぐ下の題名がレコードの名前なので重ねない)。4 件以上は、最初と直前だけを出して、あいだを「…」に畳む(押すと一覧)。左端の「←」と `Backspace` で 1 つ戻る。`Esc` はこれまでどおりパネル全体を閉じる
- パネルの参照の項目(商談の「取引先」など)は、押すと選び直し、右端の矢印でそのレコードへ進む。これで、関連リスト(親 → 子)だけでなく子 → 親へもたどれる
- 一覧の行の強調と `J` / `K` は、経路の起点(その一覧から開いたレコード)で見る。パネルの中で先へ進んでも、行の選択は動かない
- 途中のレコードを削除したら、パネルは閉じずに 1 つ前へ戻る

## 10. ビューを作る・直す(2026-09-22。Notion の型)

本人の指示: 「医療機関リスト」「金融機関リスト」、フェーズ別・重要度別のカンバンのようなビューを、個別に作らずに画面から作れるように。**Notion を全面的に手本にした**。

```
│ [icon] 取引先                                      ⏷ ⇅ ⋯ │ ⌕ ⚙ [+ 新規 N] │
│ ▤ 一覧   ▦ カンバン   ▥ レポート   ▤ 医療機関 ★ ⌄   +         │  タブ。開いているタブを押すとメニュー
│ ⏷ [業種 が 医療・福祉 ✕]  かつ  [従業員数 以上 100 ✕]  + 条件      │  条件はチップ。押すと編集
```

- **タブ** — 「+」で一覧かカンバンを足す(名前は「一覧 2」のように付く)。開いているタブをもう一度押すと、名前を変更 / 表示項目・分け方・お気に入り / 複製 / お気に入りに出す / ビューを削除。ダブルクリックでもその場で名前を変えられる。お気に入りのタブには ★
- **フィルター**(⏷) — 押すと項目の一覧が出て、選ぶと条件のチップが増え、すぐ編集(項目 → 条件 → 値)。値は型ごとに出し分ける: 選択肢は一覧(「のどれか」は複数)、利用者は「自分」も選べる、参照は検索、日付は「今日 / 明日 / 7 日後 / 今月の初め…」(サーバが解決するマクロ。04 §3)か日付の指定、数値と文字は入力。条件の間の「かつ / または」を押すと切り替わる。値が入っていない条件は薄く出し、サーバへは送らない
- **並び替え**(⇅) — 項目を足し、昇順 / 降順を押して切り替え。複数の並びは上から順
- **設定**(⋯) — 名前、レイアウト(一覧 ⇄ カンバン。切り替えると列の定義は作り直す)、表示する項目(目の印で出す・隠す、つまんで並べ替え)、カンバンは分ける項目・出す列(選択肢を押して隠す)・列の見出しの合計、サイドバー(お気に入りに出す・名前・件数)、削除
- **変えるとその場で保存する**(Notion と同じ)。確認や「保存」ボタンは無い。削除だけトーストの「元に戻す」で戻せる(論理削除)。保存は楽観更新で、失敗したら戻して知らせる(`data/views.ts`)
- 条件の入れ子(お気に入りの「今日」ビューの「期限が今日以前 または 期限が空」など)は、画面では「高度な条件」の 1 チップとして保ち、外すことだけできる。深い入れ子の編集は要るときに足す
- **ポップオーバーの入れ子** — 条件の編集(ポップオーバー)の中で値の一覧(ポップオーバー)を開く。外側は、自分より後に開いたものの中の操作を「内側」とみなす。Esc はいちばん上だけを閉じる(`ui/overlay.tsx`)。これが無いと、内側を押した瞬間に外側が閉じて選択が消える(実際に踏んだ)
