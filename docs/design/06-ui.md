# 06 UI

画面は「閲覧と台帳の修正」が主だが、入力もフル機能で持つ(01 D-03)。参照は Attio / Linear。

## 1. 構成

- **サイドバー**: インボックス / 今日 / 企業 / 担当者 / リード / 案件 / プロジェクト / 活動。下にラベルとお気に入りのビュー
- **ビュー**: 一覧(表)/ カンバン / 詳細。どのエンティティでも一覧とカンバンを切り替えられる
- **詳細**: 左に項目(カスタム項目含む)、右にタイムライン(活動)とタスク・関連レコード・ファイル
- **コマンドパレット**(Cmd/Ctrl+K): 検索と操作の主導線
- 全画面レスポンシブ。スマホでも機能を落とさない(01 D-03)

## 2. キーボード操作

一覧・カンバンで、マウスを使わず一周できること。Todoist / Linear の操作系に合わせる。

| キー | 動作 |
|---|---|
| `Q` | 新規登録(どの画面からでも。インボックスに入る) |
| `J` / `K` | 下 / 上のレコードを選択 |
| `E` | 完了にする |
| `C` | コメント(活動)を登録 |
| `Enter` | 詳細を開く |
| `Cmd/Ctrl+K` | コマンドパレット |
| `#` | プロジェクト / セクションへ移動 |
| `@` | 担当者を割り当て |
| `1`〜`4` | 優先度 |
| `T` | 期限を設定(自然文可: 明日、来週火曜) |
| `L` | ラベルを付ける |
| `/` | 検索 |
| `Esc` | 閉じる / 選択解除 |

`Q` でどこからでも素早く登録できることが Todoist 置き換えの要。既定の入れ先はインボックス(`project_id` が NULL)で、後から `#` で移す。

## 3. カンバン

**グルーピング軸を任意に選べる。**固定しない。

| エンティティ | 選べる軸 |
|---|---|
| タスク | セクション / ステータス / 優先度 / 担当者 / ラベル / 期限(今日・今週・それ以降) |
| 案件 | ステージ / 担当者 / 期待受注月 |
| リード | ステータス / 流入元 |
| プロジェクト | ステータス / 担当者 |

列間のドラッグでその軸の値が変わる(セクション軸なら `section_id`、優先度軸なら `priority`)。列の並びは `position`。

## 4. エージェントとの関係

画面で行う操作はすべて `packages/core` の同じコマンドを呼ぶ(01 D-03)。エージェントが書いたものは即座に画面へ反映され、`audit_log` の actor で「誰が書いたか」が見える。タスク完了時に llm-wiki へ ingest する流れ(現在の `todoist-complete` skill)は、MCP の `get_context` + `complete_task` でエージェント側が担う。CRM 側に ingest の機能は持たない。
