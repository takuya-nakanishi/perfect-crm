# 台帳(REC)テストケース表

読み方・資産の書き方・`—` の扱いは [`README.md`](README.md)。仕様は `docs/design/04` §2・§11、`05` §1〜§5・§8・§9。

**段階**: `入口`(ログインとホーム)、`一覧`(一覧・カンバン・レポート・絞り込み)、`パネル`(開く・編集・ぱんくず・幅)、`作成`、`削除`、`検証`(サーバの型と参照整合)。
この領域は**優先順位の 5 位**(日常の操作の軽快さと正しさ)。

L2 の対象は `frontend/src/mocks/engine.ts`(`insert` / `update` / `remove` / `restore` / `find` / `validate`)。L1 は `lib/records.ts`。
