# タスク(TASK)テストケース表

読み方・資産の書き方・`—` の扱いは [`README.md`](README.md)。仕様は `docs/design/02` §3、`05` §3、`01` D-07・D-08。

**段階**: `追加`(Q の追加欄)、`完了`(チェックと元に戻す)、`繰り返し`(Todoist の型)、`ラベル`(複数選択)。
この領域は**優先順位の 3 位**(Todoist の代わりにならないと切り替えられない。J-027)。

L2 の対象は `frontend/src/mocks/engine.ts`(`insert` の既定値、`applyRules`、`applyRecurrence`)。L1 の読み取りは [`io.md`](io.md) §3。
