# 提供元のマーク

ログインの画面とアカウントの画面で、「Google でログイン」「Microsoft でログイン」に添えるマーク(05 §15)。
色は各社が決めたものなので、トークン(`styles/index.css`)ではなく、ここに置いた SVG のまま使う。形・色・大きさの比は変えない。

- `google.svg` — Google の「G」。標準の色のまま、白い地の上に置く(暗いテーマでも。画面は白い角丸の地を敷く)。
  出典: Sign in with Google Branding Guidelines https://developers.google.com/identity/branding-guidelines
- `microsoft.svg` — Microsoft の 4 つの四角。出典: Sign in with Microsoft branding guidelines
  https://learn.microsoft.com/en-us/entra/identity-platform/howto-add-branding-in-apps
